# C3 Runtime 简化界面（正式版候选）

- 普通页面仅包括连接开关、服务地址、连接状态、版本、读取的后端和已加载模型。
- “高级设置”默认折叠，保留 SnapMark 本地后端偏好、共享 Runtime 空闲卸载时间。后者仍需确认。
- “Runtime 维护工具”是独立的非模态窗口。包括后端安装包、运行状态、服务启停/升级/回滚、已注册模型、GGUF 检查与注册。仅点击操作后才可能修改共享服务，保留现有确认、后台线程与备份策略。
- 删除空白外观页，但主编辑器里的颜色/标注设置保持不变。
- 关于窗口显示 SnapMark 主程序版本 1.0.0，而非 C2-G 开发标记。此版本号不代表 Runtime 或插件状态。
- 本次仅修改主程序和界面，**不会自动安装、启动、停止或重启共享 Local AI Runtime，亦不删除模型**。

需在 Code01 GNOME Wayland 实机确认：高级设置折叠动画、维护窗口可重复打开/关闭、每项原有维护控件可见且按钮仍按原确认流程工作。
